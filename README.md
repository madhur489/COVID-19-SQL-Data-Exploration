# 🦠 COVID-19 SQL Analysis



## 📌 About the Project

This project focuses on analyzing global COVID-19 data using SQL Server. The objective was to explore the dataset, answer real-world analytical questions, and prepare clean data for reporting.

The insights generated through SQL were later used to build an interactive Power BI dashboard.

Some of the business questions explored include:

- Which countries had the highest infection rates?
- Which countries recorded the highest number of deaths?
- How did vaccination campaigns progress over time?
- Which countries achieved the highest vaccination coverage?
- What was the peak COVID-19 day for each country?
